# Level 3: File Encryption and Decryption using Python

This project demonstrates **file encryption and decryption** using Python’s `cryptography` library (Fernet symmetric encryption).  
It securely encrypts text files and allows decryption back to original files.

---

## Features

- Encrypt any text file
- Decrypt the encrypted file
- Uses modern symmetric encryption (Fernet)
- Simple command-line interface
