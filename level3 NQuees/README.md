# Level 3: N-Queens Problem using Python

This project solves the classic N-Queens problem using the backtracking algorithm.

## Problem Description
The goal is to place N queens on an N×N chessboard such that no two queens attack each other.
This means no two queens share the same row, column, or diagonal.

## Approach
- The solution uses backtracking.
- Queens are placed row by row.
- Before placing a queen, the program checks if the position is safe.

## How to Run
1. Open terminal in the project folder
2. Run: python n_queens.py
3. Enter the number of queens (example: 4)

## Example Output
The program prints all valid board configurations.
